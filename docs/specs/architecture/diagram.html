The edge waits, the logic decides

A task waits for a socket, a timer or a channel, then calls a state machine with what happened. That call never waits.

Nothing comes twice

A sans-IO crate has no blocking or async side. The edge is async only, on Tokio. A blocking test runs the edge on a runtime of its own.

A disconnect ends the session

A hang-up or a broker going down closes the real connection. A reconnect gets a new transport and a new pipeline. The client context and shared counters stay in the engine.

A call through the pipeline

All eleven stages run inside the pipeline. At the orange ones the session acts for it: the pipeline hands out an Output, and continues when the matching Input arrives.
